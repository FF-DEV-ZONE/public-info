## 运行维护说明

### TradingView 采集项目重启

采集项目需要整体重启时，按以下顺序操作：

```bash
# 1. 先重启终端
pm2 restart tradingview-terminal

# 2. 再重启数据采集
pm2 restart tradingview-data
```

### TradingView 交易项目重启

交易项目需要重启时，按以下顺序操作：

```bash
# 1. 先重启测试终端
pm2 restart tradingview-terminal-test

# 2. 再重启交易执行
pm2 restart tradingview-trade
```
