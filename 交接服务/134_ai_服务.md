## default agent 采集项目详解

### 1. market-data-pipeline

包含两大采集模块：

#### ① 日K线采集（daily_collection.py）

| 市场 | 采集时间（北京时间） | 数据源 |
|---|---|---|
| 日本/韩国/台湾/澳洲 | 14:40 | mootdx/yfinance |
| A股 | 15:10 | mootdx/yfinance |
| 港股 | 16:10 | yfinance |
| 印度 | 18:10 | yfinance |
| 欧洲（德/法/荷/瑞/英） | 23:40 | yfinance |
| 美股 | 次日04:10 | yfinance |
| 加拿大 | 次日04:10 | yfinance |

写入表: `ai_market_data.ohlcv`

#### ② 永续合约K线采集（collect_swap_klines.py）

数据源: Binance/OKX/Bybit/Bitget
频率: 持续运行，5分钟间隔
保留期: 3个月自动清理

写入表: `ai_market_data.stock_swap_klines`

#### 附属任务

- gap_fix_loop.py — 持续运行，自动修复缺失K线
- backfill.py — 历史数据回填

### 2. sector-stocks-collector

采集方式: Node.js 持续运行

| 市场 | 采集方式 | 频率 |
|---|---|---|
| A股 | Sina API | 每1分钟 |
| 港股 | Puppeteer DOM reload | 每1分钟 |
| 美股 | Sina API | 每1分钟 |
| 英股 | Puppeteer API 拦截 | 每1分钟 |

提前30分钟预热，开盘后开始采集，收盘停止。

写入表: `ai_market_data.sector_stocks_snapshot`

### 3. minute-klines-collector

说明: 用 yfinance 拉取全市场1分钟K线，覆盖 US(CN/HK/JP/FR/DE/UK 各Top100 + SP500)
频率: 持续运行，每5分钟一轮
数据源: yfinance

写入表: `ai_market_data.minute_klines`

### 4. capital-com-1m

说明: 用 Capital.com REST/WebSocket API 拉取1分钟K线
覆盖市场: 港股/美股/英股
频率: 持续运行（盘内实时采集）

写入表: `ai_market_data.capital_com_1m`

### 5. vpa-signal

采集方式: cron 定时任务

| 任务 | 时间 | 说明 |
|---|---|---|
| 西部市场 | 周二-周六 07:00 | vpa_analyzer.py --market west |
| 亚洲市场 | 周一-周五 18:00 | vpa_analyzer.py --market asia |

写入表: `ai_market_data.vpa_signals`

## stocks_catalog 表说明

### 角色

全市场股票主数据表，定义每只股票的唯一标识、板块分类、ISIN 等核心属性。是整个数据系统的"字典表"。

### 主键

`tv_ticker`（TradingView 格式 ticker，如 `NASDAQ:AAPL`、`SSE:600519`）

### 关键字段

| 字段 | 说明 |
|---|---|
| tv_ticker | 主键，TV格式ticker |
| name | 股票名称 |
| instrument_type | 类型（EQUITY/ETF/WARRANT等） |
| exchange | 交易所 |
| market | 市场（us/cn/hk/jp等） |
| isin | 国际证券识别码 |
| gics_sector_code | GICS板块代码（美股） |
| gics_group_code | GICS组代码 |
| gics_industry_code | GICS行业代码 |
| gics_sub_code | GICS子行业代码 |
| shenwan_l1_code | 申万一级代码（A股） |
| shenwan_l2_code | 申万二级代码 |
| shenwan_l3_code | 申万三级代码 |
| tv_sector | TV板块 |
| tv_industry | TV行业 |
| classification_source | 分类来源（shenwan/gics/tv/none） |
| is_active | 是否活跃 |
| multi_listed | 是否多地上市 |

### 关联表

| 表名 | 关联字段 | 关系说明 |
|---|---|---|
| ohlcv | tv_ticker | 日K线数据，通过 tv_ticker 关联获取板块/ISIN |
| minute_klines | symbol | 分钟K线，symbol = tv_ticker |
| stock_swap_klines | stock_ticker | 永续合约K线，通过 stock_ticker 关联获取板块信息 |
| vpa_signals | ticker | VPA信号，ticker = tv_ticker |
| sector_stocks_snapshot | stock_code | 行业股票快照，stock_code 关联获取 ISIN/板块 |
| capital_com_1m | epic/isin | Capital.com K线，通过 isin 关联 |
| stock_liquidity | tv_ticker | 流动性数据 |
| stock_rating | tv_ticker | 评级数据 |
| stock_classification_override | tv_ticker | 分类覆盖 |
| v_stocks_full | tv_ticker | 全量股票视图 |
| etf_category | tv_ticker | ETF分类 |
